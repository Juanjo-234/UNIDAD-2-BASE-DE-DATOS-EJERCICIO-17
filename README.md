# UNIDAD-2-BASE-DE-DATOS-EJERCICIO-17
Se pide diseñar un Modelo Entidad-Relación (MER) para una clínica veterinaria, que permita administrar los tutores, las mascotas, los veterinarios, las consultas médicas y las vacunas aplicadas.

El modelo debe contemplar:

- Tutores: registrar DNI, nombre, dirección y teléfono. Un tutor puede tener varias mascotas.
- Mascotas: almacenar número de historia clínica, nombre, especie, raza, sexo, fecha de nacimiento estimada y color de pelaje. Cada mascota pertenece a un único tutor.
- Veterinarios: registrar matrícula profesional, nombre, teléfono y especialidad clínica.
- Consultas veterinarias: almacenar fecha y hora de atención, motivo de consulta, peso, temperatura corporal, diagnóstico y veterinario responsable.
- Vacunas: registrar código, nombre comercial, laboratorio y número de lote.
- Aplicaciones de vacunas: asociar las vacunas aplicadas a cada mascota, indicando la fecha de aplicación y la fecha sugerida para el próximo refuerzo.

Finalmente, se deben identificar las entidades, sus atributos, las relaciones y las cardinalidades, teniendo en cuenta que un tutor puede tener varias mascotas, un veterinario puede atender múltiples consultas y una mascota puede recibir varias vacunas a lo largo del tiempo.
